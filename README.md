# Dual-Wielding-Paladin
Install BepInEx

Download the latest BepInEx x64 package for Unity games:
https://github.com/BepInEx/BepInEx/releases

Unzip it into your Erenshor game folder so that you see BepInEx and doorstop_config.ini alongside the game’s .exe

Drop the DualWieldingPaladin.dll into the BepinEx/Plugins folder

How to Use

Dual Wield Skill Unlock
Paladins now have the same level-requirement as Duelists. Once you hit the appropriate level, you can learn Dual Wield.

Learning from the Skill Book

Acquire the “Skill Book: Dual Wield” (item ID 1233414).

In your inventory, hover over the book icon.

Right-click it as a Paladin.

Previously you’d have seen “Your class cannot use this item!”

Now you’ll learn the Dual Wield skill and see the normal “Learned skill: Duel Weapon Mastery” message.

Verification

Open your skillbook (B by default) and you should see “Dual Weapon Mastery – Duelist, Paladin” listed.
